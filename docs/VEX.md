# Vulnerability exploitability

[openvex.json](openvex.json) is the OpenVEX document for this repository.

A statement is added only for a component vulnerability that is present in a dependency and does not affect this app. The statement uses status `not_affected` and a justification.

As of 2026-11-01 the tree has no scanner ignore for that class of finding, and the statements list is empty. Do not add a CVE that this project has not assessed.
