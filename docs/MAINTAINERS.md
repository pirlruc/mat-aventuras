# Maintainers

| Account | Role | Access |
| --- | --- | --- |
| [pirlruc](https://github.com/pirlruc) | Maintainer | Repository admin, GitHub Actions secrets, and the release signing key |

The maintainer reviews and merges pull requests, cuts releases, and answers private vulnerability reports. There are no other maintainers.

A collaborator gets no admin, no Actions secrets, and no copy of the release signing key until the maintainer reviews them.
